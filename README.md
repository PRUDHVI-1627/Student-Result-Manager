# 📊 Student Result Manager

A browser-based student result management app that lets you add students, 
enter their marks, and instantly view grades, GPA, and pass/fail status.

## ✨ Features

- Add students with their name and subject marks
- Auto-calculates grade (A, B, C, D, F) and GPA
- Displays pass/fail status per student
- Clean table view of all results
- No database needed — runs entirely in the browser

## 🏃 How to Run

No install needed. Just open `index.html` in any browser.

```bash
# Optional: serve locally
npx serve .
# or
python3 -m http.server 8080
```
